# Precomputed Artifacts

This folder contains precomputed artifacts for the primary RRF pipeline, which uses **GPT-4o-mini** as both the question-generating and scoring model (see `configs/primary_model_locked.json`).

## Contents of `gpt_4o_mini/`

| Subdirectory / File | Description |
|---|---|
| `ablation_results/` | Nested cross-validation metrics for all ablation variants. Contains multiple CSVs covering similarity metrics (hamming, jaccard, cosine-cluster), thresholds, optimisation targets, chronological evaluation, and expert-only variants. Read by the paper notebook via glob. |
| `benchmark_results/` | Logistic regression (elastic net) benchmark comparison. |
| `vanilla/` | Vanilla zero-shot and few-shot LLM prompting baselines (6 CSVs: GPT-4o-mini, o3, o3-mini × zero-shot, few-shot). |
| `primary_results/` | Locked primary model outputs: fold metrics, summary, and manifest. Generated by `scripts/04_primary_model.py`. |
| `test_predictions/` | Raw LLM prediction CSVs per cross-validation fold. Used by the offline evaluation scripts. |
| `initial_questions/` | All generated questions before and after deduplication (all, unique, semantic-dedup variants). |
| `similarity/` | Semantic similarity matrices and heatmaps used during question deduplication. |
| `test_questions/` | Selected question lists per fold, including expert-only variants. |
| `validation_predictions/` | Validation set predictions per fold. |
| `validation_stats/` | Permutation test results and precision analysis. |
| `grid_search_results_anonymised.csv` | Comprehensive hyperparameter sweep results. |
| `archive/` | Backup copies of intermediate artifacts from earlier pipeline runs. Not used by the notebook or evaluation scripts. |

## Root-level CSV files

| File | Description |
|---|---|
| `01_question_training_data_anonymised.csv` | Training split used for question generation. |
| `02_question_validation_data_anonymised.csv` | Validation split used for question filtering. |
| `03_full_cross_validation_test_data_anonymised.csv` | Full test set used in cross-validation evaluation. |

## Alternative Question-Generating Models

Three sibling folders alongside `gpt_4o_mini/` contain results where alternative LLMs were used as the question-generating model:

- `claude_sonnet_4_5/`
- `gemini_2_5_pro/`
- `gpt_5_2/`

Each contains a **subset** of `gpt_4o_mini/`'s structure — specifically `ablation_results/` (hamming threshold sweep at six thresholds), `benchmark_results/`, and `test_predictions/`. They are used by the "Question-Generating Model Comparison" section of the paper reproduction notebook.
