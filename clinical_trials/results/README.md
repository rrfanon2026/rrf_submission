# Clinical Trials Phase I Results

These results are read by the paper reproduction notebook for the clinical trials sections.

## Files Used by the Notebook

| File | Notebook Section | Description |
|---|---|---|
| `phase_I/primary_results/primary_model_repeat_metrics.csv` | Clinical Trials: TOP Phase I Results | RRF primary model metrics across 10 repeats |
| `phase_I/logreg_results/logreg_repeat_metrics.csv` | Clinical Trials: TOP Phase I Results | Elastic net baseline metrics across 10 repeats |
| `phase_I/ablation_results/beta_sweep_summary.csv` | Clinical Trials: Recall–Specificity Pareto | Beta sweep summary for Pareto frontier figure |

## Other Files

- `phase_I/primary_results/primary_model_summary.json` — aggregated summary statistics
- `phase_I/primary_results/primary_model_manifest.json` — config and metadata
- `phase_I/logreg_results/logreg_summary.json` — logistic regression summary
- `phase_I/ablation_results/ablation_repeat_metrics.csv` — ablation metrics
- `phase_I/ablation_results/beta_sweep_repeat_metrics.csv` — detailed per-repeat beta sweep
- `phase_I/ablation_results/*.png` — pre-rendered figures

These files are generated by the clinical trials pipeline scripts but are not directly read by the paper notebook.
